## Описание проекта и функционала

Приложение разработано на платформе **WPF (.NET / C#)** с использованием **Entity Framework Core**, архитектуры стилей и словарей ресурсов согласно методическим указаниям.

### Реализованные шаги (по методичке):
- **Шаг 1. Создание БД:**
  - База данных `DB_Chernenkaya_Booking` со связанными таблицами по ER-диаграмме: `City`, `AccommodationType`, `Accommodation`, `Room`, `Users`, `BookingStatus`, `Booking`, `Service`, `BookingService`, `Payment`.
  - Настроены первичные и внешние ключи с поддержкой каскадного удаления (`ON DELETE CASCADE`).
- **Шаг 2. Первоначальная настройка WPF-приложения и главного окна:**
  - Окно `MainWindow` разделено с помощью контейнера `Grid` на 3 строки (45 / * / 45).
  - Размещен навигационный контейнер `Frame` (`MainFrame`) со скрытой панелью навигации.
  - Таймер даты и времени в правом нижнем углу (`DispatcherTimer`).
  - Кнопка «Назад» в верхнем левом углу.
  - Иконка приложения (в папке `res/`).
  - Подтверждение при закрытии окна (`Window_Closing`).
- **Шаг 3. Подключение словарей стилей и смена темы:**
  - Корпоративный стиль `Dictionary.xaml` по методичке преподавателя (цвета `#0198AF`, `#233E76`, `#F3F3F3`, `#FFFFFF`, шрифт Open Sans / Segoe UI).
  - Собственный альтернативный словарь стилей `CustomTheme.xaml` (премиальная тёмная тема для сервиса отелей).
  - Динамическое переключение тем в `MainWindow`.
- **Шаг 4. Страница авторизации (`AuthPage`):**
  - Поля ввода логина и пароля с подсказками (плейсхолдерами) и всплывающими подсказками `ToolTip`.
  - Разграничение ролей: `User` (гость) и `Admin` (администратор гостиничного сервиса).
- **Шаг 5. Капча на странице авторизации:**
  - Появление защитного кода при 3 неверных попытках входа.
  - Генерация случайного кода из латинских букв и цифр.
  - Запрет копирования, вырезания и вставки капчи (`CommandManager.PreviewExecuted`).
- **Шаг 6. Страница регистрации (`RegisterPage`):**
  - Регистрация с проверкой всех полей.
  - Проверка уникальности логина.
  - Проверка сложности пароля (от 6 символов, только английские буквы, наличие цифры).
  - Проверка совпадения двух паролей и корректности email.
- **Шаг 7. Хеширование паролей:**
  - Хеширование алгоритмом SHA-1 (`PasswordSecurity.ComputeSha1`) перед записью в базу данных и сверка хешей при входе.
- **Шаг 8. Каталог объектов размещения (`CatalogPage`):**
  - Просмотр списка отелей, апартаментов и курортов в виде карточек с фото через `ListView` и `WrapPanel`.
  - Поиск по названию и адресу в реальном времени.
  - Фильтрация по городам и типам жилья.
  - Сортировка по возрастанию/убыванию цены и по рейтингу.
  - Кнопка сброса фильтров и кнопка бронирования.
- **Шаг 9. Панель администратора (`AdminHubPage`):**
  - Меню навигации с 4 основными разделами: Объекты размещения, Номерной фонд, Бронирования, Аналитика.
  - Карточки сводной статистики: общее число объектов, номеров, броней и сумма оплат.
- **Шаг 10. Страницы работы с таблицами (CRUD):**
  - Таблицы `AccommodationsTabPage`, `RoomsTabPage`, `BookingsTabPage`.
  - Страницы добавления и редактирования с валидацией (`AddEditAccommodationPage`, `AddEditRoomPage`).
  - Каскадное удаление данных с подтверждением действия.
- **Шаг 11. Смена пароля (`ChangePasswordPage`):**
  - Проверка текущего пароля и логина, валидация нового пароля, обновление хеша в базе данных.
- **Шаг 12. Диаграммы аналитики (`AnalyticsPage`):**
  - Построение столбчатых, линейных и круговых графиков распределения бронирований по типам жилья, городам и выручке через LiveCharts.
- **Шаг 13. Выгрузка в Microsoft Word (.docx):**
  - Формирование отчета с шапкой, сводной таблицей по объектам размещения и выручке, колонтитулами и выделением итоговых сумм.
- **Шаг 14. Выгрузка в Microsoft Excel (.xlsx):**
  - Создание аналитической книги с отдельными листами («Сводная аналитика», «Журнал броней»), формулы суммирования (`SUM`), границы, форматирование валюты.
- **Шаг 15. Экспорт аналитического отчета в PDF (.pdf):**
  - Постраничная генерация официального отчета в формате PDF через `PdfSharpCore`: показатели по объектам, распределение по городам, фирменное форматирование и колонтитулы.
